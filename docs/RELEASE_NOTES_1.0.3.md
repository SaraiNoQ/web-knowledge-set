# 织页 `1.0.3`

`1.0.3` 是桌面端数据位置与文章工作台更新版。

## 主要变化

- 桌面端“数据安全 → 知识库位置”显示当前知识库路径，完整路径只通过受限 Tauri IPC 在本地显示。
- 桌面端文章默认以 Web 同款只读界面打开，点击“编辑这篇知识”后进入 Markdown 编辑、对照与预览。
- 桌面端沿用本地草稿、冲突保护和离线图片资源；本地 Web 与 Cloudflare Web 行为保持不变。

## macOS 安装包

- 支持 Apple Silicon，最低 macOS 13.5。
- 应用使用 ad-hoc 签名，未使用 Apple Developer ID，未经过 Apple 公证。
- 不包含自动更新通道；下载后请核对 `SHA256SUMS`。
