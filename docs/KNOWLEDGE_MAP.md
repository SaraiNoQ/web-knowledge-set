# 知识地图

知识地图以节点方式浏览已经保存的文章与论文。列表视图仍用于常规管理；地图用于发现分类与内容之间的关联。资料节点和文件夹关系来自已保存的资料元数据；语义连线是模型推荐，不是引用或事实关系。

## 使用

- 在“知识织片”标题切换列表和地图。全部、收藏和论文视图均可使用地图；回收站保持列表。
- 文章和论文使用不同形状；文件夹归属用实线表示。未分类资料和孤立节点继续显示。语义关联启用后会建立可恢复的分段索引；语义推荐只表示模型相似度，不表示引用或事实关系。
- 选择节点查看状态与关联，可从现有阅读器打开；点击语义推荐可以重新聚焦，切回全库会保留筛选。
- 本地资料库默认将已归档资料纳入地图，用户可以隐藏归档资料。
- 全库语义连线要求两篇资料互为前五名，并达到默认 0.60 阈值；单篇视图显示当前资料和最多 10 篇直接邻居。标题、类型、收藏和文件夹筛选会限定当前浏览范围。
- 语义模型分数表示向量相似度，不是正确率，也不表示引用或事实关系。关联列表可用键盘操作；只有当前选中或悬停的节点显示标题。

## 当前关联与隐私

文件夹归属只来自资料元数据，不会把同一文件夹的资料两两连线。语义索引默认关闭；需要单独输入 SiliconFlow API 密钥、测试模型并再次确认启用。M2 已加入本地与云端索引和状态管理；M3 已将文档向量分页加载到浏览器 Web Worker 中计算相似度。没有向量或计算失败时，文件夹地图仍可用。

索引请求固定发送到 `https://api.siliconflow.cn/v1/embeddings`，默认模型为 `BAAI/bge-m3`。文章使用已保存 Markdown 提取的纯文本；论文仅使用当前已完成提取版本的原文块。每段最多 1,500 个 Unicode 字符、重叠 150 字符，每批最多 4 段。不会发送 PDF、页图、中文译文或图片资源。页面打开时最多每 60 秒检查一次；网络和限流错误最多重试 3 次，等待约 1 分钟和 5 分钟，连续失败 3 次后暂停。

本地密钥仅存在当前服务进程内存；云端密钥保存在当前浏览器站点存储。向量与分段哈希属于可重建缓存：本地完整留档可能携带缓存，但恢复后会清除；云端知识包不包含索引，恢复后会关闭语义索引。密钥不进入任何留档或导出。

## 性能边界

首版以 1,000 篇资料为性能验收规模，不限制继续保存资料。超过该规模时仍完整显示筛选结果中的节点，但暂停语义计算并提示缩小范围。画布使用 2D Canvas；节点元数据先显示，文档向量通过分页接口单独加载，全文与分段向量不随地图接口下发。索引逐篇完成时，Web Worker 只增量比较新向量；筛选范围、内容版本或模型变化时再重建当前图。
