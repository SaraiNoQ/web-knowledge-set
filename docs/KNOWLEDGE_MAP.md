# 知识地图

知识地图以节点方式浏览已经保存的文章与论文。列表视图仍用于常规管理；地图用于发现分类与内容之间的关联。资料节点和文件夹关系来自已保存的资料元数据；语义连线是模型推荐，不是引用或事实关系。

## 使用

- 在“知识织片”标题切换列表和地图。全部、收藏和论文视图均可使用地图；回收站保持列表。
- 文章和论文使用不同形状；文件夹归属用实线表示。未分类资料和孤立节点继续显示。语义推荐是后续计划功能。
- 选择节点查看状态与关联，可从现有阅读器打开；标题、类型、收藏和文件夹筛选只影响可见结果。
- 本地资料库默认将已归档资料纳入地图，用户可以隐藏归档资料。

## 当前关联与隐私

首版只绘制本地已有的文件夹归属，不生成语义向量，也不会向外部服务发送资料内容。界面里的语义关联状态会明确显示为未启用。

后续阶段计划增加可选的 SiliconFlow 向量关联。只有在该阶段交付后，用户才能配置凭据和启用索引；届时会说明发送范围和工作量。计划发送的文章文本来自 Markdown，论文文本来自已提取的原文块，不包含 PDF、页图、中文译文或图片资源。凭据不会进入备份或导出。索引是可重建缓存，不包含在 Cloudflare 知识包中。

## 性能边界

首版以 1,000 篇资料为性能验收规模，不限制继续保存资料。画布使用 2D Canvas；较大的地图通过标题搜索和筛选缩小范围。M1 按页加载节点元数据；未来加入语义索引后，再先展示节点并分批加载向量。
