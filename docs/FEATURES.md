# 功能台账

新增功能必须先登记再开发；只有实现、服务器门禁与独立审查全部通过后，才将对应项勾选并划掉。

- [ ] **首次使用指导**：首次进入时分步介绍网页导入、资料库、Markdown 编辑、搜索与数据安全；可跳过、可再次打开，并满足键盘操作和可访问性要求。
- [ ] **Markdown 保真翻译**：文档页提供目标语言与翻译按钮；翻译结果可阅读且不覆盖原文，保留标题、列表、表格、代码块、链接、图片等 Markdown 结构，并明确网络目标与发送范围。
- [ ] **全局正文字号调整**：提高导航、表单、列表、提示、编辑器和预览正文的默认字号，同时保留标题层级、窄屏布局与可访问性。
