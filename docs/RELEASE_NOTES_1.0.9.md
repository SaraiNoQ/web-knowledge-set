# 织页 1.0.9

本次包含目录分页与渲染隔离、本地标题和正文搜索优化、启动维护等待、备份异步 I/O，以及云端分页和解压预算保护。目录每组按页显示，跨页选择保留；长文预览按需开启。

同时包含阅读设置默认进入阅读外观、控件尺寸统一、界面文案精简，以及论文中文字号保存和整理全文为独立文章等更新。Firefox 剪藏扩展更新至 0.3.11。

## macOS 安装

支持 Apple Silicon，最低 macOS 13.5。可使用 PKG 升级安装；请先保存工作并退出织页，无需卸载旧版本。安装包不替换用户资料目录。也提供 DMG 和 SHA256SUMS 校验和。

应用使用 ad-hoc 签名，未使用 Apple Developer ID，未经 Apple 公证，未配置在线自动更新。
