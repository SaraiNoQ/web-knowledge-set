# 织页前端控件规范

沿用暖纸色背景、朱红色强调、衬线阅读正文和无衬线操作文字。控件保持轻微凹凸深度，状态改变迅速；正文阅读时不做装饰动画。

| 控件 | 统一来源 | 规则 |
| --- | --- | --- |
| 动作按钮 | `src/components/ui/Controls.tsx` 的 Button / IconButton | 4px 圆角；常规40px、紧凑32px；主要动作朱红、普通动作纸色、危险动作朱红描边、导航动作透明；共享焦点、禁用和按压反馈 |
| 分段选择 | SegmentedControl | 固定轨道内沿X轴移动同一滑块；纸色选中面与朱红文字；方向键及Home/End可选项，跳过禁用项 |
| 输入与下拉 | Input / Textarea / Select及阅读数值输入 | 4px圆角、纸色凹槽、朱红焦点；菜单跟随滚动后的控件位置 |
| 文件选择与上传 | UploadZone / FilePicker / FileSelectButton | 图标、标题、操作和限制说明保持同一顺序；PDF、Markdown、书签、知识包共用布局；文件名使用操作字体 |
| 菜单与浮层 | Modal、Select菜单、HoverCard、目录Popover | 6px圆角和同一柔和投影，不再使用硬偏移阴影 |
| 动作反馈 | InteractionMotion | 共用弹簧参数；松开或失去窗口焦点后恢复；尊重系统减少动态效果；状态颜色始终可见 |

本轮审查发现的分歧来自原生按钮和共享Button混用、各页面独立绘制分段选择、PDF用标签模拟按钮而Markdown使用Button，以及旧样式中的1–5px圆角和硬阴影。现有React动作按钮已迁入Button，原生button只留在控件实现内部；外观与交互由`src/ui-system.css`和`InteractionMotion`统一管理。文档行、图标导航、数字滑块、媒体画布保留符合其用途的密度和形状，不把正文或图片当作按钮处理。

新增操作先使用共享控件；业务样式只负责布局、密度和状态，不另写按钮圆角、动画或投影。浅色、深色、减少动态和窄屏同时属于同一套控件规则。
