# 织页前端控件规范

沿用暖纸色背景、朱红色强调、衬线阅读正文和无衬线操作文字。常态以中式平面设计呈现：小圆角、细线边界和克制留白，不使用常驻凸起、凹槽或白色高光。轻微层次仅用于悬停、按压和切换反馈；正文阅读时不做装饰动画。

| 控件 | 统一来源 | 规则 |
| --- | --- | --- |
| 动作按钮 | `src/components/ui/Controls.tsx` 的 Button / IconButton | 4px 圆角；常规40px、紧凑32px；主要动作朱红、普通动作纸色、危险动作朱红描边、导航动作透明；共享焦点、禁用和按压反馈 |
| 分段选择 | SegmentedControl | 固定轨道内沿X轴移动同一滑块；平面纸色选中面与朱红文字；方向键及Home/End可选项，跳过禁用项 |
| 输入与下拉 | Input / Textarea / Select及阅读数值输入 | 4px圆角、平面纸色输入面、细线边界和朱红焦点；菜单跟随滚动后的控件位置 |
| 文件选择与上传 | UploadZone / FilePicker / FileSelectButton | 图标、标题、操作和限制说明保持同一顺序；PDF、Markdown、书签、知识包共用布局；文件名使用操作字体 |
| 菜单与浮层 | Modal、Select菜单、HoverCard、目录Popover | 6px圆角与细线边界；菜单项透明且左对齐，不使用独立卡片、常驻投影或硬偏移阴影 |
| 动作反馈 | InteractionMotion | 共用弹簧参数；松开或失去窗口焦点后恢复；尊重系统减少动态效果；状态颜色始终可见 |

本轮审查发现的分歧来自原生按钮和共享Button混用、各页面独立绘制分段选择、PDF用标签模拟按钮而Markdown使用Button，以及旧样式中的1–5px圆角和硬阴影。现有React动作按钮已迁入Button，原生button只留在控件实现内部；外观与交互由`src/ui-system.css`和`InteractionMotion`统一管理。文档行、图标导航、数字滑块、媒体画布保留符合其用途的密度和形状，不把正文或图片当作按钮处理。

新增操作先使用共享控件；业务样式只负责布局、密度和状态，不另写按钮圆角、动画或投影。浅色、深色、减少动态和窄屏同时属于同一套控件规则。

Markdown 排版有纸页（默认衬线）、极简（轻量无衬线）、书刊（更鲜明的标题与上下细线引用）、技术（紧凑层级、浅底代码和表格）四套。通过 `data-reading-style` 与现有纸色/墨色令牌组合，只改变文档正文，不改变工作台。风格应用推荐字体和行距，其余阅读参数继续由用户控制；不加载外部字体或远程样式。

编辑/返回阅读排在四个文章动作的首位，三种模式仅在编辑时显示于该按钮左侧。格式工具集中在风格与字符数所在的工具行，段落和插入使用共享 Select，格式和历史使用共享 IconButton。选区浮层使用 CodeMirror 原生 tooltip 定位与同款 SVG，保留选区、键盘焦点、只读禁用和 Esc 收起；窄屏工具栏换行。MARKDOWN/PREVIEW 使用零高度 sticky 容器与绝对定位标记，不占正文高度；各面板滚动离开顶部时，仅切换标记透明度为 .5，回顶恢复。格式工具通过 React portal 复用原编辑器状态与命令。预览使用 React 延后值与已有 memo，风格切换不重建编辑器、不重新解析正文。

实现参考：[ByteMD](https://github.com/bytedance/bytemd) 的源文/预览分离、工具动作与预览调度；[Milkdown Crepe 选区工具栏](https://github.com/Milkdown/milkdown/blob/main/packages/crepe/src/feature/toolbar/index.ts) 的非空选区、焦点与只读边界；[Vditor](https://github.com/Vanessa219/vditor) 的常用格式与插入功能组织。沿用项目已有 CodeMirror 事务、tooltip、历史与 Markdown 渲染管线，独立实现交互，不复制第三方源码、不增加编辑器依赖。本阶段仍为源文/对照/预览，不实现 Typora 式即时富文本或 Notion 式块拖拽。

目录行的图标和标题固定左对齐，悬停反馈作用于整行；透明导航按钮只改变底色，不叠加凹槽阴影，分段栏仅由平面轨道和滑块表达选中状态。组合搜索框由外层边界表示聚焦，内部输入框不重复描边；键盘操作仍有可见焦点。

文章位置栏单行至少42px并位于正文滚动区域之外；紧凑文章头部有自动高度，展示风格、模式与文章操作换行时不裁切。网页阅读的正文、AI派生和处理状态共用正文section，文章操作固定在其上方。文档标签悬停覆盖整张标签，内部标题与关闭按钮不各自绘制底色。快捷搜索头部仅保留输入框，Esc与点击遮罩仍可关闭。

文件夹标题与操作图标共享整行底色，子目录不设独立滚动区域。AI派生中，无额外输入的生成操作在桌面与分段栏同排，窄屏按钮铺满下一行；翻译分段栏仍占满生成区宽度。展开面板时正文容器不添加顶部留白。生成成功通过统一toast显示4秒后自动消失，错误信息继续保留便于处理。
