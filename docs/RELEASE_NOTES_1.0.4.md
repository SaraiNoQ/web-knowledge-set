# 织页 `1.0.4`

`1.0.4` 是 AI 连接测试修复版，基于当前 `main` 打包。

## 主要变化

- 修复远程 AI 端点 DNS 返回混合记录时被误判为“不允许的网络地址”的问题；连接测试会固定到已验证的公网地址，全部为内网、回环或保留地址时仍会拒绝连接。
- 本地桌面端连接测试失败提示改为“不会写入数据库或留档”，与实际本地存储边界一致；Cloudflare Web 继续显示 D1 提示。

## macOS 安装包

- 支持 Apple Silicon，最低 macOS 13.5。
- 应用使用 ad-hoc 签名，未使用 Apple Developer ID，未经过 Apple 公证。
- 不包含自动更新通道；下载后请核对 `SHA256SUMS`。
- 首次启动如被 Gatekeeper 拦截，请在 Finder 中右键应用并选择“打开”；不要关闭 Gatekeeper 或移除隔离属性。

升级前请先在“数据安全”中创建并验证完整留档。
