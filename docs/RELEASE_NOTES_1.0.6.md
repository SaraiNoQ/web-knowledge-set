# 织页 `1.0.6`

`1.0.6` 基于当前 main 的文章工作台更新打包。

## 主要变化

- 标签栏更紧凑，标签过多时自动压缩宽度与标题，并关闭最早打开的标签；当前未保存的文章保留。
- 右侧功能区提供 Markdown 大纲，可折叠层级并跳转正文或源码标题。
- 新增全屏图片查看器：缩放、拖动、旋转、翻转、亮度与对比度调整，以及 PNG 副本导出。原图片和文章保持不变。
- 设置界面分为“阅读与显示”和“AI 派生设置”；正文两侧总留白支持 0%–50%，自动记忆。
- 收紧目录分类按钮宽度，原网页入口移入“更多操作”，并优化快捷搜索与工作台布局。

## macOS 安装包

- 支持 Apple Silicon，最低 macOS 13.5。
- 应用使用 ad-hoc 签名，未使用 Apple Developer ID，未经过 Apple 公证。
- 不包含自动更新通道；下载后请核对 `SHA256SUMS`。
- 首次启动如被 Gatekeeper 拦截，请在 Finder 中右键应用并选择“打开”；不要关闭 Gatekeeper 或移除隔离属性。

升级前请先在“数据安全”中创建并验证完整留档。
