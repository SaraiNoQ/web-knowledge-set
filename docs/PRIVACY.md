# 隐私说明

织页是本地优先、单用户应用。没有账号、云同步、广告、遥测或崩溃数据上传；应用不会主动把知识库交给项目维护者。是否向网页站点或模型服务发送请求，由下述明确操作决定。

## 本机保存的数据

SQLite 数据库保存文档正文、标题、来源地址和元数据、一级文件夹归属、标签、集合、采集状态与历史、编辑修订、应用设置以及 AI 派生结果。数据目录还保存压缩的原始 HTML 快照、受支持的离线图片和短期导入暂存文件。

默认位置：

- macOS 桌面端：`~/Library/Application Support/io.github.sarainoq.zhiye`
- 其他 Unix 本地 Web：`~/.local/share/io.github.sarainoq.zhiye`
- 设置 `KB_DATA_DIR` 或在桌面首次引导选择的自定义空目录时：使用该目录

完整备份和诊断日志分别位于数据目录同级的 `<数据目录名>-backups` 与 `<数据目录名>-diagnostics`。桌面端自定义目录的选择记录由 Tauri 启动器保存在应用配置区；网页前端不会取得该绝对路径。桌面“数据安全”页面只通过受限 Tauri IPC 在本地显示当前路径，不经 Node API 或 Cloudflare Web 返回。用户在“数据安全”切换位置时，桌面端会在 sidecar 安全退出后迁移这些目录及数据库、快照、资源和暂存文件。

`0.9.1` 会兼容读取早期 `dev.local.zhiye` 数据目录和桌面目录指针。身份过渡只会在正式应用配置区写入一个指向原知识库的小型启动配置，不搬动知识库、备份或诊断内容；同时发现两个知识库时会拒绝自动选择。早期没有端点绑定信息的钥匙串密钥不会自动加载，以免发送给错误供应商；请在 AI 设置中为当前平台重新录入。保存或删除新绑定时会同时清理旧条目。

数据目录及其主要文件使用仅限当前系统用户的权限作为纵深防护，但它们不是加密保险库。能以同一系统用户身份运行的恶意程序仍可能读取这些数据。

## 何时会连接网络

### 网页采集

提交 URL 后，织页会访问该公开 HTTP/HTTPS 地址。直接读取失败或正文不足时，隔离 Chromium 可能请求页面引用的公开脚本、页面接口和重定向目标，以获得渲染后的正文；浏览器阶段阻止图片、字体、媒体、WebSocket、下载、权限和持久 Cookie。提取完成后，应用会另行请求 Markdown 引用的受支持图片以供离线阅读。

这些请求会向目标站点暴露正常网络信息，例如本机公网 IP、请求时间、目标路径和织页/Chromium 的请求头。织页不导入个人浏览器 Cookie，不尝试绕过登录、付费墙、验证码或反爬机制。

可选的 Chrome/Firefox 剪藏扩展只在用户点击扩展时以 `activeTab` 读取当前浏览器已经渲染的页面，并在浏览器本地转换成 Markdown。扩展不申请 Cookie、历史或全部网站权限，不读取 Cookie 数据库，也不上传登录凭证、完整 DOM、表单值或登录态图片字节。用户核对并确认后，扩展才把标题、HTTP(S) 来源、安全元数据和 Markdown 发到固定的 `https://clip.sarainoq.cn`，云端 Worker 随后按 Markdown 图片地址尝试从公网抓取并写入私有 R2；失败图片仍只保留原始链接。每次保存为新副本；随后只向已打开的 `https://zhiye.sarainoq.cn` 标签页注入一个包含新文档 ID 的本地刷新事件，不读取该标签页内容，也不把事件发送到网络。

Firefox 正式包使用浏览器内置数据同意声明：配对码与撤销型 Bearer 令牌属于 `authenticationInfo`，来源 URL 属于 `browsingActivity`，正文属于 `websiteContent`，可能出现的聊天或消息属于 `personalCommunications`。四类数据都只在用户主动配对或点击确认保存后发送；扩展不声明可选遥测，也不在后台自动采集。

### 可选 AI

AI 默认关闭，关闭时不会自动发送文档或产生派生结果。保存 AI 设置本身不会发送正文；摘要等预设指令在用户点击“获取”后直接发送，只有自由“AI 对话”会先展示 Prompt、准确文本与网络目标，再由用户手动确认。

用户即使未开启 AI，也可以显式点击“测试连接”。该操作只向当前表单中的端点发送两条固定的 `ZHIYE_OK` 探针消息，并将最大输出限制为 16 tokens；它不读取文档、不保存设置或模型回复，也不开启 AI。远程供应商仍可能对这一小次请求计费或按其政策保留请求。

摘要、提纲、关键词和标签建议在用户点击“获取”后发送文档标题和 Markdown 正文，最多 40,000 个字符；超长文档使用稳定片段，不再额外展示 SEND PREVIEW。自由 AI 对话还会发送用户明确输入的 1–4,000 字符 Prompt；Prompt 仅用于当次预览和生成，不写入 SQLite、D1、派生结果或留档，持久记录只保留不可逆的 Prompt 哈希标识。翻译任务在用户点击“获取”后，会把不超过 100 万编辑器字符的完整 Markdown 拆成最多 64 个顺序请求，只发送可译文本片段及稳定 ID；代码、链接和图片地址不发送。一次长文翻译可能产生多次供应商请求和费用，任一批失败或取消都不保存半成品，手动重试会从第一批重新发送。远程 OpenAI-compatible 端点可能按其自己的隐私、保留和计费政策处理数据，使用前应单独审阅供应商政策。本机端点也会把文本交给监听该 loopback 地址的进程。

端点和模型设置保存在 SQLite。派生结果保存模型、不可逆端点标识、提示版本、输入哈希、输出和可用的用量信息。远程 API 密钥与一个规范化 HTTPS 端点绑定，不写入数据库、导出或浏览器响应：macOS 桌面端使用系统钥匙串，并同步更新当前 sidecar 进程；本地 Web 的应用内输入只保存在当前服务进程内，重启即清除。Web 也可在启动时成对设置 `ZHIYE_LLM_API_KEY` 与 `ZHIYE_LLM_API_ENDPOINT`；服务读取后会立即从自身环境删除，缺少任一项时不会加载密钥。

Cloudflare Web 的 AI 平台与模型设置保存在 D1。API Key 与规范化端点绑定后，以明文保存在 `zhiye.sarainoq.cn` 的浏览器站点存储中，刷新和重开浏览器后仍可用；它只随显式连接测试或确认生成请求发给同域 Worker，不写入 D1、R2 留档或诊断数据。能访问同一浏览器配置文件、页面脚本或已解锁共享设备的人可能读取该密钥；共享设备使用完毕后应在 AI 设置中删除。云端翻译当前单次最多发送 40,000 字符，并校验 Markdown AST、Front Matter、代码、HTML 和链接目标未被改写。

### 用户主动打开的链接

点击预览中的外部链接会交给浏览器访问目标站点。只有配置了签名更新通道的正式桌面构建才支持更新检查，而且必须由用户点击“检查更新”触发；源码和未签名构建不配置更新通道。

## 备份、导出与诊断

完整备份包含数据库、HTML 快照和离线图片，足以恢复整个知识库。便携知识包和单篇 Markdown 用于迁移或分享，可能包含正文、来源、一级文件夹名称、标签、集合及离线图片。它们都不是匿名数据。

“数据安全”可把一份已校验完整备份导出为 `.zhiye-backup`。该文件未加密，直接包含数据库、HTML 快照和离线资源；不包含 API 密钥，但仍应当按完整知识数据保管。导入会先限制文件为 2 GiB、50,000 个条目，再严格校验 ZIP 路径、CRC、清单、SHA-256、schema 和可用空间。通过后只新增一份“已校验留档”，不会覆盖当前资料或自动恢复；恢复仍需要用户另行确认。

Cloudflare Web 使用私有 R2 bucket 保存 `.zhiye-cloud-backup`。v5 以 JSON manifest 携带文档图片清单，导出 ZIP 另含 `assets/<sha256>` 图片内容；v1/v2/v3/v4 JSON 仍可导入，旧归档按未收藏、未删除默认值恢复，不包含 API Key 或扩展 Bearer Token。manifest 文件未加密且上限 8 MiB，文件夹、文档与 AI 结果合计 32 条；v5 ZIP 导入请求上限 64 MiB、解压后 96 MiB，图片按内容哈希校验。恢复前先创建当前副本，再使用 D1 原子 batch 切换并撤销旧扩展配对。

Cloudflare Web 的 D1/R2 数据与本地知识库相互独立，不会自动同步；只有用户明确执行的导出、导入或恢复才会移动数据。

Cloudflare Web 直接抓取会把公开 URL 和随机任务 ID 写入 Cloudflare Queue，再由 Browser Run 请求页面并转为 Markdown。目标站会看到 Cloudflare 出口网络、请求时间和路径；此路径不使用个人浏览器 Cookie，需要登录的页面仍应使用剪藏扩展。

诊断日志使用固定 allowlist，只记录时间、稳定事件/错误码、模式、时长和非负计数；每个文件最多 1 MiB，最多 8 个文件，保留 7 天。诊断包只包含版本、运行平台、schema、队列计数、完整性计数、最近备份概况、稳定错误码和这些脱敏日志；默认不含正文、标题、标签、URL、查询参数、Cookie、密钥、HTML 快照、绝对路径或 AI 输入输出。

诊断包不会自动上传。运行时间、平台、错误种类和使用规模仍可能具有识别性，因此分享前必须人工检查包内 `diagnostics.json`、`logs.jsonl` 和 `README.txt`。

## 删除与保留

- 移入回收站不会删除数据；只有明确执行永久删除才会删除数据库记录，并在无其他引用后回收相关文件。
- 删除一级文件夹只删除分类记录，其中的文档会保留并转为“未分类”。
- AI 结果可逐条删除，也可关闭 AI 并删除全部派生结果。
- 自动备份默认保留最近 7 份，可在“数据安全”修改为 1–100 份；手动、迁移前和恢复前备份不会按每日备份策略自动删除。
- 卸载应用不保证删除知识库、备份、诊断目录或 macOS 钥匙串条目。确认备份后需分别处理它们。

不要把真实数据库、备份、`snapshots/`、`assets/`、诊断包或 API 密钥提交到 Git、粘贴到 issue，或发送给不受信任的人。
