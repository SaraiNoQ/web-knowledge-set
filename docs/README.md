# 织页

织页是单用户、本机运行的互联网知识库：输入公开网页 URL，应用会优先直接读取网页，必要时回退到隔离的 Chromium，再把正文保存成可编辑、可搜索的 Markdown。SQLite 是唯一事实源，网页 HTML 快照和允许类型的图片保存在同一知识库目录中。

> 当前仓库版本为 `0.9.1` 发布候选构建。主要功能已经冻结，但尚未提供签名、公证的正式 macOS 安装包；源码构建未配置签名更新通道，请勿把它当作正式发行版。

## 已有功能

- 公开网页采集、失败重试、队列暂停、采集历史和从已有快照重新提取。
- Markdown 编辑、预览、自动保存、修订历史和冲突保护；重新采集或 AI 结果不会静默覆盖人工正文。
- 标题、正文、来源的中英文搜索，以及标签、集合、收藏、归档、回收站、筛选和当前页批量操作。
- JPEG、PNG、GIF、WebP、AVIF 正文图片的受限本地缓存；缓存失败时保留 Markdown 中的原始地址并显示占位信息。
- 单篇 Markdown、便携知识 ZIP、Netscape 书签、Markdown 和多 URL 的导入导出。
- 可校验的完整备份、恢复、数据健康检查、孤儿快照清理和本地诊断包。
- 默认关闭、逐篇确认的 OpenAI-compatible AI 摘要、提纲、关键词、标签建议与 Markdown 保真翻译。翻译作为独立结果保存，不覆盖原文。

## 开始使用

桌面端首次启动会显示引导，跳过后也可从顶部的“使用指南”再次打开。默认数据目录由 macOS 管理；正式应用标识对应：

```text
~/Library/Application Support/io.github.sarainoq.zhiye
```

首次引导可选择其他目录，但只能选择真实、空的文件夹。选择只在桌面进程中完成，绝对路径不会返回网页界面；应用会安全退出，并在下次启动使用新目录。这个操作不会搬迁旧知识，迁移数据请使用“数据安全”中的完整备份与恢复。

本地 Web 模式在启动前用 `KB_DATA_DIR` 指定目录：

```sh
KB_DATA_DIR=/你的/知识库目录 pnpm start
```

浏览器不能在服务运行时切换数据目录。未指定时，macOS 使用上述目录，其他 Unix 系统使用 `~/.local/share/io.github.sarainoq.zhiye`。服务只监听随机或指定的 `127.0.0.1` 端口；终端输出的一次性 `ZHIYE_READY` 地址用于建立本地会话，使用后令牌会从地址栏移除。

早期开发构建使用 `dev.local.zhiye` 目录和钥匙串服务。`0.9.1` 首次启动时，如果只发现一个旧知识库或旧桌面目录指针，会将正式启动配置安全指向原位置，不搬动或复制 SQLite、留档与诊断数据。早期未绑定端点的钥匙串密钥不会自动加载，请在 AI 设置中为当前平台重新录入；保存或删除时会清理旧条目。若新旧两个目录都含数据，应用会明确停止而不打开空库；先保留两份数据，再通过完整留档合并。本地 Web 模式冲突时请用 `KB_DATA_DIR` 明确选择。

### 日常流程

1. 在页首输入不含账号密码的 HTTP/HTTPS 公开网页地址。
2. 等待“直接读取”或“浏览器采集”完成；正文过短、图片失败和其他质量问题会显示明确警告。
3. 编辑 Markdown、标题、作者、发布日期和来源备注，用标签与集合整理。
4. 遇到外语内容时，点击文档动作区的“翻译”，选择目标语言，核对发送范围后再确认。
4. 在“数据安全”查看健康状态并创建完整留档。便携知识包用于迁移或分享，不等同于可恢复的完整留档。

编辑内容约 800 ms 后自动保存，也可立即保存。关闭窗口或切换文档时，如果仍有未持久化修改，应用会阻止或提示确认。

### 快捷键

| 快捷键 | 操作 |
|---|---|
| `Command/Ctrl + K` 或 `/` | 聚焦搜索 |
| `J` / `K` 或方向键 | 在知识列表中移动 |
| `X` | 选中或取消当前行 |
| `Enter` | 打开当前行 |
| `Command/Ctrl + S` | 立即保存 |
| `Esc` | 关闭面板或返回列表 |
| `?` | 打开快捷键帮助 |

## 数据、备份与恢复

数据目录包含数据库 `zhiye.sqlite3`、`snapshots/`、`assets/` 和短期导入暂存目录。不要在应用运行时直接复制或修改这些文件，也不要用同步盘对其中的单个文件做双向同步。

完整备份保存在数据目录的同级 `<数据目录名>-backups` 目录中，包含一致的数据库副本、网页快照、被引用的离线图片、版本化清单和 SHA-256。应用每日首次启动最多自动备份一次，默认保留最近 7 份；数据库迁移和恢复前也会先尝试备份。可以在“数据安全”中修改自动备份保留数、重新校验和恢复。

恢复会先校验格式、哈希、数据库结构和空间，再创建恢复前备份并切换数据。数据库迁移只向前追加；旧版本应用不支持打开较新 schema。更新或换版本前先做完整备份，回退时不要让旧应用直接打开已经升级的数据目录，详见 [SUPPORT.md](./SUPPORT.md#更新失败与版本回退)。

## 网络与隐私边界

- 织页没有账号、云同步、遥测或崩溃数据上传。
- 网页采集会连接用户提交的公开地址；浏览器回退还可能加载该页面引用的公开脚本或接口。所有请求均拒绝回环、私网、链路本地及其他非公网地址。
- 登录态网页、Cookie 导入、付费墙、验证码绕过、PDF、内网页面和整站爬取不受支持。
- AI 默认关闭。启用后仍须逐篇预览并确认准确发送文本；远程端点必须是 HTTPS，本地端点只能是显式信任的 loopback 地址。
- 诊断信息仅保存在本机，导出也不会自动上传。分享前仍应人工检查。

完整说明见 [PRIVACY.md](./PRIVACY.md) 和 [SECURITY.md](./SECURITY.md)。

## 当前限制

- 静态网页响应和浏览器最终 HTML 上限为 5 MiB；静态读取最多 5 次重定向、15 秒。
- 浏览器回退最长 30 秒、单次网络预算 25 MiB，并阻止图片、字体、媒体、WebSocket、下载、权限和持久 Cookie；提取完成后再单独缓存正文图片。
- 默认每张离线图片最多 10 MiB、每篇最多 100 张且合计最多 100 MiB；只缓存内容类型与文件签名一致的受支持格式。
- 不支持 SVG、视频、样式表或脚本的离线归档。图片缓存失败不会让整篇文章失败。
- 没有浏览器扩展、移动端、Windows/Linux 正式包、云同步、多人协作、PDF/OCR、知识图谱或向量检索。

## 开发

开发环境规则见 [AGENTS.md](../AGENTS.md)，完整路线和发布门槛见 [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md)，待开发功能见 [FEATURES.md](./FEATURES.md)。本地目录只用于编辑与同步源码；禁止在本地安装依赖、构建、测试或启动开发服务。所有这些操作都在 `root@campus-server:/root/dev/zhiye` 完成。

服务器使用固定 Node `24.19.0`：

```sh
npx -y node@24.19.0 /usr/lib/node_modules/corepack/dist/pnpm.js install --frozen-lockfile
npx -y node@24.19.0 /usr/lib/node_modules/corepack/dist/pnpm.js check
npx -y node@24.19.0 /usr/lib/node_modules/corepack/dist/pnpm.js test
npx -y node@24.19.0 /usr/lib/node_modules/corepack/dist/pnpm.js test:e2e
```

远端开发服务固定一个 localhost 端口：

```sh
KB_PORT=4173 KB_DATA_DIR=/root/dev/zhiye/.data npx -y node@24.19.0 /usr/lib/node_modules/corepack/dist/pnpm.js dev
```

需要从本机浏览器访问时，另开终端建立 SSH 隧道：

```sh
ssh -L 4173:127.0.0.1:4173 root@campus-server
```

然后打开终端打印的 `ZHIYE_READY` 地址，不要只访问端口根地址。Tauri 外壳、sidecar 和 Chromium 可在服务器完成平台无关及 Linux 检查；最终 macOS 包必须在受控 macOS runner 上生成和验证。
