# 织页 `1.0.5`

`1.0.5` 从最新主线打包，包含 `1.0.4` 之后的资料库、论文阅读器、知识地图和剪藏更新。

## 主要变化

- 论文原文与中文对照阅读、逐页图片输入、分批提取、独立滚动、缩放和分栏调整。
- 知识地图与默认关闭的可选语义关联索引。
- 收藏、回收站、一级文件夹和精简资料库视图；云端留档图片可导入本地。
- 剪藏扩展 `0.3.7` 支持 X 长文正文，改进懒加载图片与媒体密集文章处理；Web 帮助页提供签名 Firefox 安装包。
- 恢复遗漏在旧分支的 Web favicon，并隔离 Web 静态资源与扩展包构建。

## 安装与更新

- Apple Silicon，最低 macOS 13.5；应用使用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证。
- 升级前在旧版本“数据安全”中创建并验证完整留档，然后退出应用。
- 下载 DMG 和 `SHA256SUMS`，核对摘要，将新应用拖入“应用程序”替换旧版本；知识库沿用原目录。
- 本版没有自动更新通道。不要用旧版本打开升级后的知识库。
- 如首次启动被 Gatekeeper 拦截，在 Finder 中右键应用并选择“打开”；不要关闭 Gatekeeper。
