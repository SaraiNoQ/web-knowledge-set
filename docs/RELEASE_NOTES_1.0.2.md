# 织页 `1.0.2`

`1.0.2` 从当前 `main` 打包，包含云端抓取、图片资源和云端留档兼容性修复。

## 主要变化

- 云端公开网页抓取优先使用页面声明的 Markdown 入口，降低动态文档抓取失败率。
- 云端正文图片支持引用式 Markdown、标题和复杂 URL，并按内容哈希缓存到 R2。
- 云端留档导出兼容旧版 1.0.1 应用的重复来源 URL 限制。
- 桌面端使用新的“纸页 + 交织线”织页图标。

## macOS 安装包

- 支持 Apple Silicon，最低 macOS 13.5。
- 应用使用 ad-hoc 签名，未使用 Apple Developer ID，未经过 Apple 公证。
- 不包含自动更新通道；下载后请核对 `SHA256SUMS`。
